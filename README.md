# OGE Exam Preparation App 📚📱

A native Android application designed to help middle school students prepare for the **OGE (State Final Examination)** through interactive tests, dynamic scoring, and structured study material.

---

## 🚀 Features

* **Interactive Practice Tests:** Multiple-choice and input-based questions covering core OGE subject topics.
* **Instant Feedback & Score Tracking:** Real-time checking of user answers with detailed scoring.
* **Clean UI/UX:** Intuitive interface designed in accordance with Android Material Design guidelines.
* **Offline Access:** Practice and review key materials without needing an active internet connection.

---

## 🛠 Tech Stack & Tools

* **Platform:** Android (Java)
* **IDE:** Android Studio
* **Build System:** Gradle
* **Version Control:** Git & GitHub
